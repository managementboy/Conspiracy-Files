From the tested repository root, after claiming the game through the established
automation workflow:

```bash
tools/autotest/pz.sh eval -f tools/autotest/checks/map_media.lua
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.start("map-build01")'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.mark("before-acquisition")'

tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.maps()'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.here("before-read")'
```

Interact through the normal game reading path. For explicitly labelled synthetic
control cases, the map(index) helper returns an existing enumerated inventory
item; calling the native onCheckMap with that item exercises its normal Lua
path, but does not substitute for natural loot acquisition. There is no helper
that creates a map or prepares a stash. Never prepare a vanilla stash a second
time merely to discover whether preparation already happened.

Useful read-only calls:

```bash
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.status()'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapReadObserver.event(1)'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.stash("after-read")'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.square(12546,1393,0,"gallery-target")'
tools/autotest/pz.sh eval 'return ConspiracyFiles.MapMediaProbe.stop()'
```

The coordinate is an annotation target, NOT a verified carrier. Use square() on
actual loaded carrier coordinates you identify. It inspects one square, up to
32 objects, four containers each and 256 item entries total. Any unloaded,
unknown, truncated or zero-carrier sample cannot prove contents were preserved.
Capture actual relevant carriers, not just the example coordinate.

status() returns: active, suspended, last sequence, candidate count retained in
the ring, attachment count retained, dropped rows, observer errors. The ring
holds 192 rows; use console.txt for full history. event(sequence) returns a copy
of one row. maps() logs up to 512 inspected inventory items over four nested bag
levels and returns map count, inspected count, truncation. Its indices are
session-local, not durable identities.

Logs start with **[CF-MAP-READ]** and **[CF-MAP-WORLD]**. Preserve the full lines,
not only the last few console lines. After reload, load the helper and start a
new labelled observer session; the observer itself intentionally does not persist.

## Observation matrix

| Scenario | Required evidence |
|---|---|
| Acquire a natural annotated map without reading | Record source/design/copy identity; no read-candidate merely from acquisition or inventory enumeration. |
| Read an owned map | check-enter, reader-attached and successful check-return correlate to one call; read-candidate has the actual design ID, native read flag, and no observer errors. |
| Read from a remote container | Transfer-queued onCheckMap return has no attachment/candidate; its completed callback produces a candidate only after reader attachment. |
| Cancel that transfer, including a previously read map | No new candidate; an already-true native read flag alone cannot qualify. |
| Close immediately after opening | Trace presentation then close; do not claim comprehension or a timed-paper-reading action. |
| Reread / second copy of same design | Both real presentations are observable; same design, distinguishable copies when IDs available. No trail activation is implemented here. |
| Ordinary regional map and two annotated designs sharing a base map | Generic/base map ID must not be mistaken for annotated design identity. Capture design before and after native stash processing. |
| Reveal on world map | reveal-enter/return are separate from the original paper presentation; no extra read-candidate solely from reveal. |
| Save/reload and repeat reads | Item/design/native-read evidence survives according to native behavior; trace restarts explicitly and labels the new session. |
| Target visited before reading versus reading first | Capture loaded carrier contents before/after map read, target loading, first carrier inspection and reload. Include the gallery annotation target and actual stash anchor as distinct places. |
| Debug off / multiplayer | start refuses; original reading remains functional; no canonical writes. |
| Stop and restart observer | Native reading still works, other wrappers remain installed, one candidate per observed completed invocation rather than accumulating observer copies. |
