# Weekend run — for the owner

Autonomous testing under P4-R73 to P4-R76. The full list is
`TEST_CATALOGUE.md`; every automated result is in
`evidence/linux-autotest/`. This page is only what you need on Monday.

## What to do first on Windows

The build on Workshop is the newest DEV build named in the Workshop change note. Case rules changed
(generator g11, then g12), so **start a new game** to play a case; an older save's case is set
aside on load (P4-R77), and nothing is deleted.

## Fixed and verified in the real game (Linux)

1. **Completing a case stopped everything after it.** The next case could
   never be prepared, map marks stopped being written and proximity hints
   switched themselves off. Fixed; the core-loop check now completes a case
   and sees the next one arrive.
2. **The survivor's papers never opened by themselves** (the fix of 09-11
   waited for a panel button the game never makes for loose items). They now
   start in a free off hand, which is the only way the panel shows them.
3. **Wrong object names**: "C dplayer" → "CD player", "i dcard" → "ID card".
4. **A staff photograph was a letter**, listed as "Handwritten cover letter".
   It is now a real photograph item.
5. **Own ticket called someone else's**: a ticket or credit card with the same
   name as the ID beside it is no longer "another person's card".
6. **"The body itself wore: young."** — that outfit id is no longer printed.
7. **A new survivor after a death got no papers.** Fixed; the death check now
   dies, respawns and checks the notebook and the papers.
8. **A clue taken from a car got no map mark** (a car's containers have no map
   square of their own). It now uses the car's position.
9. **Developer items could become evidence** ("Debug fluid, marked …"). They
   are excluded; "press id" now reads "press ID".

## Decisions only you can make

1. **Papers in hand at start.** Opening them automatically requires holding
   them (off hand, only if free). Keep, or would you rather they stay closed?
2. **Other "Handwritten cover letter" subtitles.** An employment record, a
   rent statement and a public notice use the letter carrier too, so their
   list subtitle says "Handwritten cover letter". Relabel the letter carrier
   to something neutral (for example "Letter or form"), give them their own
   carriers, or leave it?
3. **Outfit words in "The body itself wore: …".** Some game outfit ids are
   styles, not clothes: Classy, Goth, Punk, Redneck, Biker, Hunter. They read
   as "wore: goth". Keep, reword ("dressed like a …"), or suppress?
