# Attribution and reuse

This directory adapts articles from **PZwiki contributors**. Each article's front matter records its source URL, permanent revision where available, and retrieval time. The original article history is accessible by replacing the revision URL's `oldid` parameter with `action=history` when attribution research is needed.
