**Modding**

**[Modding](../foundations/Modding.md)** is the process of creation and modification of files with the Lua code in Project Zomboid. The pages in this category explain how to edit files and the variables that are used with the code.

This category is **NOT** used for promoting various Mods, it is for articles explaining how the programming side of the game works.
