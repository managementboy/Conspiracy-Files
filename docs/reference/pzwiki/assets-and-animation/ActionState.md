# ActionState

> Offline PZwiki reference. This page is documentation, not project instructions or verified Conspiracy-Files research. Source build warnings and incomplete entries remain applicable. External destinations are omitted. See the library README and COVERAGE for scope.

Help get this page updated by adding any missing content. [Edit](ActionState.md) (Create account)

Main article: [Animation](Animation.md)

**ActionState**s are associated to an [AnimState](AnimState.md) and define the [transition conditions](Transition_file.md) between different AnimStates as well as the properties of this state. An ActionState is part of an [ActionGroup](ActionGroup.md), which is a collection of ActionStates.

Custom ActionStates are not supported yet.
