Character rigs are tools used in 3D softwares to facilitate the [animation](Animation.md), [rendering](Rendering.md) and [modeling](Modeling.md) process by providing a structured framework for manipulating character models. For animation, this usually involves different technics such as Inverse Kinematics (IK) and Forward Kinematics (FK) to control the movement of character limbs and joints, more commonly referred as bones.
