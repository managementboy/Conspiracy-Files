**Hot reloading** is a process that allows modders to directly apply changes of their mod files in-game without having to reload the game. This is often used for [Lua](../lua-api/Lua_API.md), [Animations](Animation.md) and [Modeling](Modeling.md) but can also be used for [Scripts](../scripts/Scripts.md).

This can be done via the [Debug menu](../foundations/Debug_menu.md) (F11) but is easier to manage via the Community Debug Tools.
