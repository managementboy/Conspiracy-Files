The **Mapping Tools** by Gruxor, also known as Crater, aims to provide a Community Edition of the tools which forks the Build 42 official mapping tools and merging parts from [Alree's Mapping Tools](Mapping_tools_Alree.md) and adding their own changes on top of it. One flaw it aims to correct is the lack of git history with the official tools as Alree's version lacked direct link to the original repository, making it difficult to track changes and merge updates from the official tools.
