Main article: [craftRecipe](craftRecipe.md)

The`Tags` parameter is used to define specific conditions that need to be respected to be able to craft. The tags are defined by the following format:



```text
-- single tag
Tags = tag1,

-- multiple tags
Tags = tag1;tag2;...,
```



<a id="Example"></a>

## Example



```text
Tags = InHandCraft;CanAlwaysBeResearched,
```
