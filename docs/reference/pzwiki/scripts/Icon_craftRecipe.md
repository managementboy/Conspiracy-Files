This article is about icons for [craftRecipe scripts](craftRecipe.md). For icons for [item scripts](item_scripts.md), see icon.

The`Icon` parameter is used to define the icon of the recipe. This parameter will refer to a texture in the game files. This seems to be used only once in the vanilla recipes with the entry`Icon = "Item_WaterDrop",` as the icon usually defaults to the items that will be crafted.

<a id="Example"></a>

## Example



```text
Icon = "Item_WaterDrop",
```
