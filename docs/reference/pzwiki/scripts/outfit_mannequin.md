This article is about outfit parameter of [mannequin scripts](mannequin_scripts.md). For outfits in the game, see Outfit.

The`outfit` parameter is used to define the outfit used by the mannequin. The available outfits are defined in the`media/clothing/clothing.xml` file. See Outfit for the full list of outfits available in the game.

## Example



```text
model = Mannequin_Scarecrow,
```
