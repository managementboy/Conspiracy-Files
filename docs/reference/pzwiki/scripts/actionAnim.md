Main article: [timedAction (scripts)](timedAction_scripts.md)

The`actionAnim` parameter is used to define the animation played during a timed action. It is defined by a performing action script. To use an action animation in a timed action, use the following format:



```text
actionAnim = <action name>,
```



See performing action for the full list of available animation actions.

<a id="Example"></a>

## Example



```text
actionAnim = PackingBox,
```
