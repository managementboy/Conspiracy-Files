The **PZ Data** project is a collection of datasets which provide data regarding [Scripts](Scripts.md), [Translation](../translations/Translation.md), [Lua](../lua-api/Lua_API.md) and [Java](../java/Java.md). It is composed of 2 types of datasets:

- Data types - manually written datasets which provide various documentation written by hand by the community.
- Parser types - automatically generated datasets from the game files, be it the decompiled Java code or the [Lua](../lua-api/Lua_API.md) files.

They are notably used to provide schemas for validation of translation files. Schemas for the XML files of the game are also provided here.
