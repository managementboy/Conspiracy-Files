Main article: [craftRecipe](craftRecipe.md)

The`time` parameter allows you to set the time it takes to finish the craft. The value doesn't have a set unit, so refer to other vanilla crafts and testing values to get an idea of the time needed for your custom craft.

<a id="Example"></a>

## Example



```text
time = 100,
```
