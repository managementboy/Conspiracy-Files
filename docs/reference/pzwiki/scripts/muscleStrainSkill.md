This parameter should be used alongside [muscleStrainFactor](muscleStrainFactor.md) and [muscleStrainParts](muscleStrainParts.md).

Main article: [timedAction (scripts)](timedAction_scripts.md)

The`muscleStrainSkill` parameter is used to define the skill that reduces the muscle strain generated during a timed action. It is defined by a skill name. To use a muscle strain skill in a timed action, use the following format:



```text
muscleStrainSkill = <skill name>,
```



<a id="Example"></a>

## Example



```text
muscleStrainSkill = Strength,
```
