Main article: [mannequin (scripts)](mannequin_scripts.md)

The`model` parameter is used to define the model used by the mannequin. The available [models](../foundations/File_formats.md#Modeling_and_animation_formats) are found inside`media/models_X/skinned`, for example:

-`FemaleBody`
-`Female_Skeleton`
-`MaleBody`
-`Male_Skeleton`
-`Mannequin_Scarecrow`
-`Mannequin_Skeleton`

<a id="Example"></a>

## Example



```text
model = Mannequin_Scarecrow,
```
