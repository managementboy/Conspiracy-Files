## CustomName

**Field:** `TilePropertyKey.CUSTOM_NAME`

**Type:** `string`

Used to define the item name, which will show as GroupName + [CustomName](tile_properties.md#customname). For example if CustomName is set to `Bed` and GroupName is set to `Fancy`, it will show as `Fancy Bed` in the game. `GroupName` is used as a sub-category description of the object, such as its color, shape, name or quality.

Those properties need to be the same for multi-tile objects.

## Facing

**Field:** `TilePropertyKey.FACING`

The direction the object is facing. This is not the orientation, but the direction the objects front looks towards. If the value is `South`, it means the tile has a north orientation and thus would be facing south.

You can find an image which shows the directions of the game [here](../../pzwiki/mapping/Tile_properties.md).

Allowed values:

> - `North`
> - `East`
> - `South`
> - `West`

## PickUpTool

**Field:** `TilePropertyKey.PICK_UP_TOOL`

**Type:** `string`

PickUpTool will indicate what tool the player needs to use to pick up the tile, while PlaceTool will indicate what tool the player needs to use to place the tile.

If you want to add new tools, you can usually use the [ItemTags](../java/item_tags.md) that you add to your item tools, or you can also look into the lua file `media/Moveables/ISMoveableDefinitions.lua` to see how they add each new tools.

The [PickUpLevel](tile_properties.md#pickuplevel) is used to determine what level in the relevant skill you need to be able to pickup the tile. For example `Hammer` with a PickUpLevel of 2 will require a carpentry level of 2 to pickup the tile.

The PickUpWeight will determine how much the tile weights in the inventory. This value is divded by 10, so for example a weight of 200 will mean an in-game encumbrance of 20. If [ForceSingleItem](tile_properties.md#forcesingleitem) is set to `true`, this is the total weight, otherwise this is the weight of each tile as a separate item.

[CanBreak](tile_properties.md#canbreak) can be used to indicate that the tile has a chance to break when being picked up. The chance gets smaller based on the [PickUpLevel](tile_properties.md#pickuplevel).

Allowed values:

> - `None`
> - `Hammer`
> - `Crowbar`
> - `Electrician`
> - `Cutter`
> - `Shovel`
> - `Wrench`

## Surface

**Field:** `TilePropertyKey.SURFACE`

**Type:** `integer`

**Default:** `0`

[Surface](tile_properties.md#surface) is used to indicate the height in pixel on the tile of the flat surface of the tile, which is notably used for tables to indicated at which height items will be placed.

A second effect of this parameter can be triggered by setting [IsSurfaceOffset](tile_properties.md#issurfaceoffset) to `true`, which will instead make the Surface parameter indicate the bottom height of the tile, which is useful for object tiles which are placed on top of other tiles, such as flower pots or lamps.

When the tile can be placed on another tile surface but also has a surface itself, the [ItemHeight](tile_properties.md#itemheight) parameter can be used to indicate the height of the surface of the tile itself, and the Surface and IsSurfaceOffset parameters will then be used for the height of the bottom surface of the tile.

You can find a demonstration of these properties on the wiki [here](../../pzwiki/mapping/Tile_properties.md)
