# Mapping

Various documentations used for [mapping](../pzwiki/mapping/Mapping.md). You will find documentations of tile properties, room names and the procedural distributions.

Procedural distributions is the system used to manage the loot of the game. Different rooms will contain different distributions, which are lists of items that can be found in that room and different properties of those found items.

Note

For more information, see the wiki page about [Procedural distributions](../pzwiki/foundations/Procedural_distributions.md).
