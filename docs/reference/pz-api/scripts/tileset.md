# tileset

**Soft Override:** Unknown

Used to define properties of tiles of tilesets.

<a id="hierarchy"></a>

## Hierarchy

This block can be a child of the following blocks:

- [spriteModel](spritemodel.md#scripts-spritemodel)
- [tileGeometry](tilegeometry.md#scripts-tilegeometry)

This block can have the following child blocks:

- [tile](tile.md#scripts-tile)

<a id="id"></a>

## ID

This block should have no ID.

<a id="parameters"></a>

## Parameters

<a id="scripts-tileset-name"></a>

### name

**Type:** string

The name of the tileset. For example `furniture_bedding_01`.
