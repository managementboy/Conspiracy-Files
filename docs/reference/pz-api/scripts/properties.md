# Properties

**Soft Override:** Unknown

Define stat changes applied to the player drinking this [fluid](fluid.md) or properties for a [tile](tile.md).

<a id="hierarchy"></a>

## Hierarchy

This block can be a child of the following blocks:

- [fluid](fluid.md#scripts-fluid)
- [tile](tile.md#scripts-tile)

<a id="id"></a>

## ID

This block should have no ID.

<a id="parameters"></a>

## Parameters

<a id="scripts-properties-alcohol"></a>

### alcohol

**Type:** float

No description provided.

<a id="scripts-properties-calories"></a>

### Calories

**Type:** float

The number of calories this fluid provides when consumed.

<a id="scripts-properties-carbohydrates"></a>

### Carbohydrates

**Type:** float

The amount of carbohydrates this fluid provides when consumed.

<a id="scripts-properties-endurancechange"></a>

### enduranceChange

**Type:** float

The amount of endurance given back.

<a id="scripts-properties-fatiguechange"></a>

### fatigueChange

**Type:** float

The amount of fatigue this fluid changes when consumed. Positive values increase fatigue, negative values decrease it.

<a id="scripts-properties-flureduction"></a>

### fluReduction

**Type:** float

No description provided.

<a id="scripts-properties-foodsicknesschange"></a>

### foodSicknessChange

**Type:** float

The amount of food sickness provides.

<a id="scripts-properties-hungerchange"></a>

### HungerChange

**Type:** float

The amount of hunger this fluid changes when consumed. Positive values increase hunger, negative values decrease it.

<a id="scripts-properties-lipids"></a>

### Lipids

**Type:** float

The amount of lipids (fats) this fluid provides when consumed.

<a id="scripts-properties-painreduction"></a>

### painReduction

**Type:** float

The amount of pain this fluid reduces when consumed.

<a id="scripts-properties-proteins"></a>

### Proteins

**Type:** float

The amount of proteins this fluid provides when consumed.

<a id="scripts-properties-stresschange"></a>

### StressChange

**Type:** float

The amount of stress this fluid changes when consumed. Positive values increase stress, negative values decrease it.

<a id="scripts-properties-thirstchange"></a>

### ThirstChange

**Type:** float

The amount of thirst this fluid changes when consumed. Positive values increase thirst, negative values decrease it.

<a id="scripts-properties-unhappychange"></a>

### UnhappyChange

**Type:** float

The amount of unhappiness this fluid changes when consumed. Positive values increase unhappiness, negative values decrease it.
