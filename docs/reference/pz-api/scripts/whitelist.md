# whitelist

**Soft Override:** Unknown

Whitelists a fluid to be allowed to put inside a fluid container.

<a id="hierarchy"></a>

## Hierarchy

This block can be a child of the following blocks:

- [component FluidContainer](component/component-fluidcontainer.md#scripts-component-fluidcontainer)

<a id="id"></a>

## ID

This block should have no ID.

<a id="parameters"></a>

## Parameters

<a id="scripts-whitelist-fluid"></a>

### fluid

**Type:** string

A fluid which is allowed to be put inside this fluid container.
