# ROOT-Blends

**Soft Override:** Unknown

**Is Root:** True

**No comma:** True

**Root patterns:** `Blends\.txt$`

The `Blends.txt` file is used in the [mapping tools](../../../pzwiki/mapping/Mapping.md) to assign blend tiles around the tiles you paint.
