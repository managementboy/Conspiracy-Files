# ROOT-TileGeometry

**Soft Override:** Unknown

**Is Root:** True

**Root patterns:** `media\/tileGeometry\.txt$`

The `tileGeometry.txt` file is used to register the tile depth of tiles. The file needs to be located inside the [common/media](../../../pzwiki/foundations/Mod_structure.md) folder.

<a id="hierarchy"></a>

## Hierarchy
