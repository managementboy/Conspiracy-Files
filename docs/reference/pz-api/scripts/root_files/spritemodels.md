# ROOT-SpriteModels

**Soft Override:** Unknown

**Is Root:** True

**Root patterns:** `media\/spriteModels\.txt$`

The `spriteModels.txt` file is used to register [models](../model.md) and animations to tiles. This is notably used for radio items as well as doors and ramps.

<a id="hierarchy"></a>

## Hierarchy

This block can have the following child blocks:

- [spriteModel](../spritemodel.md#scripts-spritemodel)

## Parameters
