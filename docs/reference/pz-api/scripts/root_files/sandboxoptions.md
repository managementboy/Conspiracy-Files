# ROOT-SandboxOptions

**Soft Override:** Unknown

**Is Root:** True

**Root patterns:** `media\/sandbox-options\.txt$`

The root of a sandbox options file. The file should be stored in the following path:



```
📁 media
  📄 sandbox-options.txt
```



You can find more information about sandbox options [here](../../../pzwiki/scripts/Sandbox_options.md).
