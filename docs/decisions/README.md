# Architecture / Technical Decision Records

Use this directory for durable decisions made after implementation research begins.

Recommended naming:
`ADR-0001-short-title.md`

Project/governance policies may use `PM-GOV-###-short-title.md` when they govern
evidence and promotion rather than one architecture mechanism.

Each record should state:
- status;
- context;
- decision;
- alternatives considered;
- consequences;
- affected requirements/research references.

Do not use ADRs to overwrite product decisions silently. Product decisions remain traceable in `/DECISIONS.md`.
