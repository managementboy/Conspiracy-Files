# Deepened idea 2 — agricultural causal chain

The agricultural account should require each link in order: a real experimental program predates the outbreak; a safety or handling failure occurs; exposure travels beyond the work itself; timing allows that exposure to be read as causal; later descriptions obscure the connection. The axiom set avoids a specific pathogen or a deliberate release.

This keeps the theory falsifiable at the story level: generic agricultural equipment alone is not enough. A future clue must support a link in the chain, and its rival reading must explain the same record through response failure.
