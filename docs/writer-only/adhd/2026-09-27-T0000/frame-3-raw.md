# Frame 3 — joint rival-reading pass
Prompt: Compare the two accounts as competing readings of the same sparse record. Find the shared evidence families and the distinct inference each account can make. Do not write clue rows or fictional document text.

- A delayed warning can mean officials did not know what was happening in time, or that an agricultural hazard was recognized and kept narrow.
- A movement restriction can be a failed attempt to contain a spreading emergency, or the visible response to exposure that began outside the response system.
- A missing or reclassified record can hide a botched operation, or hide the program that made the event possible.
- Emergency supplies in ordinary distribution channels can mark a strained response, or the route by which program materials and public consequences met.
- Medical clusters can follow disrupted evacuation and care, or an exposure pathway; neither interpretation should depend on a single named place or person.
- Keep each theory's strongest claim distinct: one concerns response decisions and their aftermath; the other concerns an agricultural malfunction and its path to exposure.
- Pressure test: if a record only says “officials were involved,” both accounts can absorb it. It becomes useful only when its timing, location, or consequence creates a different but still fair inference.
- Balance test: no recurring object type, room, institution, or scene should automatically signal one side. The evidence class is neutral; the specific fact and its placement do the work.
